# AI 3D Forge 快速上手

**用一句话描述你想要的东西，AI 帮你设计出可以直接 3D 打印的模型。**

不需要懂编程，不需要安装 Python / Node.js，不需要打开命令行。

> **完整说明**（每个功能的细节、常见问题、疑难解答）见
> **[docs/USER_GUIDE.md](docs/USER_GUIDE.md)**。
> 这份文件只讲「最短路径」：装好 → 配好 → 出第一个模型。

---

## 1. 装

双击 **`AI-3D-Forge-Setup.exe`** → 一路「下一步」。

- 默认装到 **D 盘**（省 C 盘空间），可自行改路径
- 安装程序会顺带装好免费的 3D 引擎 **OpenSCAD**（约 21MB，1～3 分钟）
- 系统要求：Windows 10 1809+ / Windows 11（64 位），约 400 MB 磁盘空间

装完双击桌面图标即可打开。如果它改为在**浏览器**里打开，说明系统缺少 WebView2 组件，
页面顶部会给出一键安装入口 —— 功能完全一致，不影响使用。

---

## 2. 配（只做一次）

打开软件后跟着**欢迎向导**走，绿色的项不用管，只需要处理两项：

| 项目 | 怎么做 |
|---|---|
| **打印机** | 选你用的机型（不确定就选「通用 FDM 打印机 220×220×250」）。选对了，AI 才会按你这台机器的喷嘴和成型范围设计 |
| **OpenSCAD** | 没装就点 **[自动安装 OpenSCAD]**：官方源下载 → 校验完整性 → 安装 → 实测一次 |
| **DeepSeek API Key** | 到 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 建一个 Key，粘进向导 → **[测试连接]** |

API Key 只存在你自己的电脑上（Windows 凭据管理器），不会上传。

---

## 3. 用

在右侧输入框里用平常说话的方式描述：

```
设计一个桌面手机支架，高度100mm。
```

```
做一个直径80mm、高40mm的圆形花盆，底部要有个10mm的排水孔。
```

一次生成通常 **20～60 秒**。有具体数字时，软件会先给你一张**规格卡片**确认理解，
确认后才开工 —— 这一步能挡掉大部分「做出来根本不是我要的」。

生成完可以在中间窗口旋转查看，右侧会给出**打印性检查**（评分 + 问题 + 怎么改）和
**预计耗材**。要改就说人话：

```
高度改成150mm。
```

改完软件会告诉你**这次到底动了什么**（该改的改了没、别处动了没）。
只调尺寸的话，直接改参数后点 **[应用参数]**，几秒钟，不消耗 AI 额度。

---

## 4. 打

装过切片软件的话，结果卡片上会有一个 **[送到切片软件]** —— 点一下直接打开，不用自己找文件。
否则点 **[下载 3MF]**（带毫米单位，不会出现“导入后大 10 倍”）
→ 拖进切片软件（Cura / PrusaSlicer / Bambu Studio / OrcaSlicer）→ 切片 → 拷到打印机。

项目文件都在 `文档\AI-3D-Forge\Projects\` 下（`.scad` 源码 + `.stl` 模型 + `.3mf`）。
**卸载或升级都不会删除你的项目和 API Key。**
删掉的项目也不是一次就没：它们先进回收站，在 **设置 → 文件位置 → 回收站** 里可以恢复；
只有在那一页点「彻底删除」并再确认一次，才是真删。
