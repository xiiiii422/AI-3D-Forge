----------
AI 3D Forge（AI 3D 打印设计工具）本体由本项目作者开发，采用 **MIT 许可证**发布，
许可证全文见仓库根目录的 `LICENSE`。

二、本软件「不包含」OpenSCAD，但会按你的确认安装它
------------------------------------------------
本软件需要一个独立的开源程序 OpenSCAD 来完成 3D 建模与 STL 导出。

  * OpenSCAD 官方网站：https://openscad.org/
  * 许可证：GNU General Public License 第 2 版（GPLv2）或更新版本
  * 许可证全文见同目录下的 LICENSE-OpenSCAD-GPLv2.txt
  * OpenSCAD 源代码：https://github.com/openscad/openscad

关于分发方式的说明（GPLv2 合规）：
  本软件的安装包中**没有**打包 OpenSCAD 的二进制文件。
  安装程序与软件运行时，会在你确认后从 OpenSCAD 官方渠道
  （files.openscad.org，该地址由 OpenSCAD 官网 downloads 页面链接）
  下载官方发布的安装包，并在下载后校验官方公布的 SHA-256 校验值；
  校验不通过则立即删除并中止安装。
  因为分发给最终用户的是**未经修改的官方二进制**，并且本说明提供了
  许可证全文与对应源代码的获取地址，符合 GPLv2 对再分发的要求。

你始终可以自行从官方网站下载安装 OpenSCAD，本软件会自动识别已安装的版本。

四、你的数据
------------
本软件不会上传你的模型、项目或 API Key。
唯一的对外网络请求是：
  * 调用你自己配置的 DeepSeek API（api.deepseek.com）进行 AI 设计与检查；
  * 在你确认后，从 OpenSCAD 官方网站下载安装包。

你的 API Key 保存在本机 Windows 凭据管理器中（不可用时退回仅当前用户可读的本地配置文件）。
你的项目与模型保存在你的用户目录中，卸载或升级本软件都不会删除。

五、AI 生成内容的提示
--------------------
模型由 AI 根据你的自然语言描述生成。虽然软件会做几何封闭性、尺寸与打印性检查，
但请在实际打印前自行确认模型的强度、尺寸精度与安全性，
尤其是承重件、受力件或与人身安全相关的用途。
