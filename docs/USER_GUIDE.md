# AI 3D Forge 用户指南

**用一句话描述你想要的东西，AI 帮你设计出可以直接 3D 打印的模型。**

你不需要懂任何编程，也不需要安装 Python、Node.js 或配置环境变量。
双击安装 → 打开软件 → 输入一句话 → 下载 STL → 交给切片软件打印。

> 只想先跑起来？看根目录的 [快速上手](../README-用户.md)。
> 这份文档是**完整指南**：安装、配置、生成、修改、打印、疑难解答。

## 一、系统要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 1809 或更高 / Windows 11（64 位） | 打包与安装器都按 x64 构建 |
| 磁盘空间 | 约 400 MB | 程序本体约 40 MB + OpenSCAD 约 21 MB + 你的项目 |
| 网络 | 生成模型时需要 | 调用你自己配置的 DeepSeek AI；预览与已生成的项目完全离线可用 |
| 显示 | 任意分辨率；窗口最小 1080×700 | 3D 预览需要 WebGL（系统自带） |
| WebView2 | 建议有 | 缺失时自动回退到系统浏览器打开，功能完全一致（见 [2.2](#22-如果软件打开后是一个浏览器页面)） |
| 其他 | 无需 Python / Node.js / 管理员权限（推荐有） | 免安装版可完全免管理员 |

## 二、安装

### 2.1 运行安装程序

双击 **`AI-3D-Forge-Setup.exe`**。

1. 如果 Windows 弹出「是否允许此应用对你的设备进行更改」，点击 **是**。
   （安装程序需要这个权限来创建开始菜单和桌面快捷方式。）

2. 阅读许可说明（本软件采用 MIT 许可证），点击 **下一步**。

3. **选择安装位置**。安装程序默认会装到 **D 盘**（如果你有 D 盘），
   这样不会占用你系统盘（C 盘）的空间。你也可以点「浏览」自己选一个位置。

4. 一路点击 **下一步** 即可完成安装。

安装程序会帮你做好这些事：
- 创建程序目录与必要的子目录
- 创建桌面快捷方式（默认勾选）
- 创建开始菜单快捷方式
- 检查你的电脑上有没有 OpenSCAD（3D 建模引擎）
- **自动帮你装好 OpenSCAD**（约 21MB，视网速 1～3 分钟）并完成首次检查

> **为什么要等一两分钟？** 安装程序会顺便把免费的 3D 建模引擎 OpenSCAD 一起装好。
> 这样你第一次打开软件就能直接生成模型，不用再等一次下载。
> 如果这一步没有成功，**完全不影响软件安装** —— 首次打开软件时会再引导你一次，
> 或者你自己去 [openscad.org](https://openscad.org/) 免费下载安装也行。

> 如果安装过程中弹出提示说需要管理员权限，那是 Windows 的正常权限机制，
> 点击「是」即可。软件不会在未经你同意的情况下做任何系统级改动。

### 2.2 如果软件打开后是一个浏览器页面？

正常情况下打开软件会弹出**独立窗口**。如果它改为在你的浏览器里打开，
说明你的系统缺少微软的 **WebView2 运行时**组件（Windows 11 与较新的 Windows 10 都自带，
少数企业版或精简版可能没有）。

这时页面顶部会有一条提示：写清楚缺的是什么、为什么仍然能用，旁边就是 **[一键安装]**。
软件会调用 Windows 自带的 `winget` 装这个组件；`winget` 用不了时，改从微软官方服务器
下载并静默安装（这一步可能弹一次管理员授权）。装完关掉页面、重开软件，就是独立窗口。

> 不想现在装？点 **[知道了]** 收起提示，继续用浏览器也没问题。
> 错过那条提示也不要紧：**系统诊断 → 运行环境 → 原生窗口组件** 一行上有同样的 **[自动修复]**。
>
> **功能在任何情况下都完全一致**，不影响使用。

### 2.3 你的文件保存在哪里？

| 内容 | 位置 |
|---|---|
| 程序本体 | 你选择的安装目录（默认 `D:\Program Files\AI 3D Forge`） |
| 项目与模型 | `文档\AI-3D-Forge\Projects\`（每个项目一个文件夹，里面是 `.scad` 和 `.stl`） |
| 设置与 API Key | `%APPDATA%\AI-3D-Forge\`（Windows 用户配置目录） |

**升级或卸载软件都不会删除你的项目和 API Key。** 程序和你的数据是分开存放的。
卸载时软件会明确告诉你数据还在哪里，你不必担心模型被删掉。

**删掉的项目怎么找回？** 在侧栏删除项目不会真的把文件删掉，而是先进回收站
（项目文件夹里的 `.deleted` 目录）。打开「设置 → 文件位置 → 回收站」就能看到它们，
点「恢复」就会回到项目列表（同名冲突时会自动加后缀，绝不顶掉现有项目）。
「彻底删除」是唯一真正删文件的动作，按下去还要再确认一次，删完无法恢复。

## 三、首次配置（只需要做一次）

第一次打开软件，会出现 **欢迎向导**，它会自动检测你的电脑环境：

```
✓ Windows 环境
✓ 软件运行环境
✓ OpenSCAD
✓ 3D 模型引擎
✓ 项目目录
⚠ DeepSeek API 尚未配置
```

绿色打勾的项你什么都不用做。只需要处理带 ⚠ 或 ✗ 的项目：

### 3.1 选择你的打印机

告诉软件你用的是哪台 3D 打印机。**这一步很重要**，因为不同机器的差别很大：

| 你的机器 | 最小壁厚应该做到 |
|---|---|
| 0.4mm 喷嘴（绝大多数机器） | 1.2mm |
| 0.6mm 喷嘴 | 1.8mm |
| 0.8mm 喷嘴 | 2.4mm |
| 光固化（树脂） | 0.4mm |

软件内置了常见机型的真实规格（Bambu Lab、Prusa、Creality、Voron、Anycubic 等），
也可以自己新建一台。选好之后，AI 就会按**你那台机器**的喷嘴、成型范围、
能不能用 ABS、最大悬垂角来设计，而不是按一台"平均打印机"。

向导里有一步会让你选，选完也可以随时在 **设置 → 打印机** 里改。
不确定的话就选「通用 FDM 打印机 220×220×250」。

### 3.2 如果提示「未检测到 OpenSCAD」

点击 **[自动安装 OpenSCAD]** 按钮，软件会：
1. 从 OpenSCAD 官方网站下载安装包
2. 校验文件完整性（防止下载被篡改）
3. 自动安装并找到 `openscad.exe`
4. 运行一次测试，确认真的能用

完成后会显示：**「OpenSCAD 已安装并配置完成。」**

> 如果因为权限或网络原因自动安装失败，软件会明确告诉你原因，
> 并提供官方网站链接和最少的操作步骤（通常是：下载 → 双击 → 下一步 → 回到软件点「重新检测」）。

### 3.3 配置 DeepSeek API Key

AI 设计功能需要 DeepSeek 的 API Key（这是按用量计费的，费用很低）。

> 上面是按默认的 DeepSeek 写的。想改用免费的智谱 GLM 也可以（设置 → AI 服务 → 使用模式 /
> 服务地址）；换过之后，系统诊断里那一项会显示你**实际配的那家**（如「智谱 GLM API」），
> 指引里的网址也跟着变，不会一直让你去 DeepSeek。

1. 打开 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 注册并创建一个 API Key
2. 把它粘贴到向导的输入框里
3. 点击 **[测试连接]** 确认可用
4. 点击 **[完成]**

你的 API Key 只保存在你自己的电脑上（Windows 凭据管理器），**不会上传到任何地方**。

### 3.4 选择使用模式（免费 / 付费 / 混合）

软件顶部与「设置 → AI 服务」里都有一个「模式」选择，随时可改：

| 模式 | 花销 | 适合 |
|---|---|---|
| **免费·GLM Flash** | 0（智谱免费档） | 先试试效果、轻度使用 |
| **DeepSeek·付费均衡** | 按量计费，单价很低 | 日常主力，质量与成本均衡 |
| **混合·性价比** | 只付生成的钱 | 想要更稳定的结构质量，又不想在“理解需求、检查”这些环节花钱 |

混合模式下：**生成和修改模型**用 DeepSeek（钱花在结构质量上），
**理解需求、打印性检查、改动复核**用智谱免费档。

> 使用不同服务商需要各自的 API Key（智谱在 open.bigmodel.cn 申请）。
> 软件的 Key 按服务商**分开保存**，切换模式不会覆盖另一家的 Key；
> 清除其中一个也不会影响另一个。
> 免费档高峰期偶尔会“访问人数过多”，软件会自动重试，必要时临时改用同服务商其他免费模型，不会静默失败。

### 3.5 外观：普通 / 液态玻璃（可选，随时能改）

**设置 → 外观** 里有三项，改完立即生效，不用重启：

- **外观主题**：浅色 / 深色 / 跟随系统。
- **界面材质**：普通（实底）或 **液态玻璃**。玻璃会让卡片、顶栏、侧栏变半透
  并模糊背后的内容，鼠标经过时表面还有一道跟着走的高光。
- **透明度**：只有选了液态玻璃才会出现这个滑块。0% = 完全不透明，最大 60%，默认 25%；
  往右更通透，往左更结实。

**弹窗、下拉菜单、提示条不跟着变透。** 这不是漏掉，是刻意做的：它们背后压着整页文字
或者 3D 场景。我们拿截图像素逐点量过：透明度开到 60% 时，普通卡片上的字仍然够清楚，
但弹窗正文会掉到读不动 —— 所以浮层始终用“厚玻璃”，不管滑块放多高，实测读数都不变
（浅色弹窗 4.78~4.86:1，而阅读无障碍的国际标准是 4.5:1）。

> 不想看到任何半透明效果？Windows **设置 → 个性化 → 颜色 → 透明效果** 关掉，
> 软件里的玻璃会自动退成实底，不用你去改软件设置。
> 同理，**设置 → 辅助功能 → 视觉效果 → 动画效果** 关掉后，页面切换动画也会降到几乎不可见。

> 主题与材质都记在软件设置里（位置见 [2.3](#23-你的文件保存在哪里)），卸载重装后还在。

## 四、开始设计模型

### 4.1 用一句话生成模型

在主界面右侧的输入框里，用平常说话的方式描述你想要的东西：

```
设计一个桌面手机支架，高度100mm。
```

```
做一个直径80mm、高40mm的圆形花盆，底部要有个10mm的排水孔。
```

```
帮我做一个壁挂式的钥匙挂钩，带3个钩子，能拧在墙上。
```

写得越具体，结果越接近你想要的。可以提到的信息：
- **尺寸**（高度、直径、长度，单位都是毫米）
- **用途**（承重、装饰、收纳）
- **细节**（要不要开孔、圆角、镂空）

点击发送后，你会看到进度一步步推进：

```
正在理解你的需求…
正在整理需求规格…
（等你确认需求）
正在设计结构…
正在生成 3D 模型…
正在检查模型尺寸与结构…
正在进行打印性检查…
已完成。
```

中间的过程通常需要 **20～60 秒**。进度条会按阶段真实推进；
「等你确认需求」那一段**故意不动** —— 因为那一步取决于你，而不是取决于程序。

### 4.2 先确认「我理解得对不对」（推荐别跳过）

如果你在需求里给了具体数字（例如「高度100mm」），
软件会先把这句话整理成一张**规格卡片**，摆在对话框里让你过目：

```
你要的模型：桌面手机支架
┌──────────┬──────────┐
│ 高度      │ 底座宽度  │
│ 100mm     │ 80mm      │
│ 你指定     │ 你指定     │
└──────────┴──────────┘
这几点你没说清，我按常见做法先定了：
  · 壁厚没指定，按你的机型取了 1.6mm
[就是这样，开始设计]  [取消]
```

- 数字标着**「你指定」**的，是你亲口说的，之后的修改不会被擅自改掉。
- 哪里理解错了，点**「改数字」**直接改，再点「按我改的来，开始设计」。
- 还有别的要求，写在下面的输入框里（例如「底部要加防滑垫」）——
  这句话会被**记住**，之后每一轮都不会忘。
- 需求很简短、没有数字时（例如「做个钥匙扣」），这一步会自动跳过，不打扰你。

> 这一步是「防止做出来的东西根本不是你要的」最有效的办法。
> 想关掉的话：设置 → 生成 → 关闭「生成前确认需求理解」。

### 4.3 查看 3D 模型

生成完成后，模型会出现在中间的预览窗口里：

- **左键拖动** 旋转
- **右键拖动** 平移
- **滚轮** 缩放

工具栏上还可以：
- **重置视角** —— 回到初始角度
- **线框模式** —— 看到内部结构
- **尺寸标注** —— 在模型上标出真实尺寸（见 [4.4](#44-在预览里直接读尺寸)）
- **自动旋转** —— 全方位查看

窗口角落会显示模型的关键数据：尺寸、三角面数、体积、预计耗材。

### 4.4 在预览里直接读尺寸

不用把模型下载下来量，预览窗口里就能读到真实毫米数。点工具栏的
**尺寸标注**按钮（标尺图标）开启或关闭，默认开启。

**没选任何一条边时**：画面上给出模型的**整体外包络**——宽、深、高三条尺寸线，
旁边各挂一个数字标签（例如 `w 80.0` `d 70.0` `h 77.7`）。这三条线量的是
模型在实际打印坐标系里的最大外形：宽 = X 方向，深 = Y 方向，高 = Z 方向，
和切片软件里看到的方向一致，不是屏幕上「看起来多宽」。

**点击模型上某一条棱线时**：只报**这一条边**的长度（`该边 80.0 mm`），
那条边同时会被高亮成一根细柱，方便确认选中的到底是哪一条。

- 边很细也没关系：判定范围按**屏幕像素**算，不管放大缩小都一样好点。
- 被模型挡在后面的棱线不会被误选（会做遮挡判断）。
- 点空白处、按 **Esc**、或点提示条上的**取消选择**，都会回到整体尺寸。
- 关掉「尺寸标注」时不能点边，也不会凭空出现标签（空预览里不会留着
  「点击棱线」这种做不到的提示）。

左上角的提示条会跟着状态变：没选边时写「点击模型上的棱线看该边长度」，
选了边就写「已选边 xx mm」并给出取消按钮。左下角浮层里的「尺寸（毫米）」
和画面上的标签来自同一次测量，两处数字不会各说各话。

> 数字随视角实时移动：标签钉在模型上的那个点，旋转时它跟着跑，
> 转到模型背后就自动隐掉；压到浮层时会自己让开，不会被盖住。

### 4.5 看懂「打印性检查」

每次生成后，AI 会像一位经验丰富的打印师傅一样检查这个模型，并给出：

- **评分**（0-100）和结论（可以打印 / 可以打印但有注意事项 / 存在打印风险）
- **具体问题**，例如：
  - 「最薄处只有 1.2mm，低于常见打印机的可靠成型尺寸」
  - 「模型底面不在地面上，切片时可能需要手动放平」
- **怎么改**（每条建议都是可以直接执行的）

这些结论不是 AI 凭空猜的，而是基于软件对 STL 文件做的**真实测量**（尺寸、体积、是否封闭实体等），
并且是**对着你选的那台打印机**下的结论。同一句话在不同机器上含义完全不同：
「1.4mm 壁厚」在 0.4mm 喷嘴上完全合格，在 0.8mm 喷嘴上就不够结实。

### 4.6 「是不是一整件」也会被实测检查

软件会导出 STL 后做两件事，都是测量、不是猜测：

1. **数一数模型由几个互不相连的实体组成。** 你要的是「一件东西」，
   如果实际是「一个主体 + 几块散的」，软件会直接告诉你：
   > 模型由 3 个互不相连的零件组成（不是一整件），打印出来需要自己拼装或粘接。

2. **用水平面剖开模型，看容器内腔里有没有不该有的材料。**
   常见毛病是外壁加强筋没贴合外形轮廓、从外壁「穿」进了桶里：
   > 在内腔范围内检测到 4 处不与内壁相连的材料截面（高度约 9mm、37mm、65mm、92mm）。

发现这两类问题时，软件会**自动把实测数据（哪一件、多大、在什么位置）交回给 AI
重新修正一次**，而且只在「确实变好了」的时候才替换掉你正在看的模型 ——
修不好就保留原样，不会越修越差。

### 4.7 AI 会「看一眼」模型外观

每次生成后，软件会把模型渲染成两个视角的图（一个斜前方、一个俯视），
交给能看图的 AI **真的看一遍**，重点找那些数字测不出来、但一眼能看出的问题：

> 桶口边缘有两个小凸起，与加强筋和夹持功能不对应，疑似长错位置。

为什么不能只靠测量：有些错误的所有指标都是正常的。实测过一次，
模型是 1 个连通实体、完全封闭、尺寸也对，但外壁的几根加强筋实际长进了桶的内腔里 ——
数字全绿，看图才知道不对。

- AI 说「未发现明显问题」= 它确实看过，并且没看出毛病；
- AI 没给出结论时，软件会如实说是「没有结论」，**不会当成「没问题」**。

### 4.8 这个件要花多少料

预览窗口角落会给出**预计耗材**，例如：

> 预计耗材（PLA）：111–191 g ｜ 约 37.2 m 线材 ｜ 含支撑 3.1 g

为什么给的是一个范围而不是一个数：实际用量取决于切片参数（几层墙、多大填充率）。
软件按「2 层墙 + 15% 填充」算出一个下限，按实体等效算出上限：

- **备料请按上限**，这样不会打到一半没料；
- 薄壁件（壁只有一两毫米）实际更靠近上限，厚实件更靠近下限 ——
  软件会用实测壁厚告诉你这个模型属于哪种。

支撑量是**估算**：按悬垂面下方全空来算，偏大。它会随摆放方向变化，
所以如果某个方向特别费支撑，软件会提示你换方向。

### 4.9 尺寸超了会自动处理

如果你要的尺寸放不进你的打印机，软件**不会**直接把一个装不进机器的模型丢给你：

1. 先用实测尺寸让 AI 重新设计（可能会改成分件）
2. 如果还是超，就自动等比缩放到刚好装得下，并告诉你缩放了多少

所以你会看到类似这样的提示：

> 已等比缩放到 71%，现在可以放进这台打印机。如需原始尺寸，请改为分件打印。

如果你确实需要原始尺寸，那就得换一台更大的机器，或者把模型拆成几件分别打印再粘起来。

## 五、修改模型

有三种修改方式，从简单到灵活：

### 5.1 直接说怎么改（推荐）

在对话框里继续说：

```
高度改成150mm。
```

```
把底部的圆角改大一点。
```

```
在侧面加两个直径4mm的螺丝孔。
```

软件会保留原来的设计，只按你的要求修改，通常也是 20～60 秒。

改完之后，结果卡片上会给你一句**核对结论**，说明这次到底动了什么：

> ✓ 这次改动只动了你要改的地方
> 　　高度已按你的要求改成 150mm，其它尺寸保持不变。

如果 AI 顺手改了别的地方，它会如实说出来，而不会假装没事：

> ⚠ 顺带改了没让你改的地方
> 　　被顺带改动：底座宽度（80 → 120）

这种情况软件会**先自己重做一次**；仍然改不干净时，会直接把你要改的那一项
写回原模型（其它一个字都不动），而不是把一个「越改越歪」的版本交给你。
实在改不好时，它会明说「这次改动不算成功」，不会让你以为改好了。

除了软件自己逐项量尺寸核对，每一步改动还会让 AI **再看一眼两份代码**，
专门查那些「数字都对、但结构被改坏了」的情况——比如底座被改窄到站不稳、
承力的地方被削薄、本来落在平台上的支撑变成悬空。这类问题光比数字看不出来。

> 只有你说过的、并且确认过的尺寸才受保护。所以你越是用第一张规格卡片
> 把要求写清楚，后面每一轮改动就越听话。

### 5.2 拖动参数（最快，秒级）

模型下方会列出它的**参数**（例如「高度 100mm」）。
直接改成新数值，点击 **[应用参数]**，几秒钟就能重新生成 —— 这种方式**不消耗 AI 额度**。

参数较多时（5 个以上且确实跨类），它们会按用途**分栏**摆放：
**整体尺寸 / 孔与螺纹 / 壁厚与强度 / 圆角与配合 / 数量与阵列 / 其它参数**，
每栏标题右侧的数字是这一栏有几个参数。你改过哪一栏，那一栏的标题就会亮起点标记，
方便在长列表里一眼找回改动的地方。参数很少时仍保持平铺，不会硬塞标题。

适合微调尺寸、比例这类改动。

### 5.3 改回之前的版本

每个项目都会自动保存历史版本（左侧项目面板里可以看到），随时可以回到之前的版本。

> 切换到别的页面（例如「设置」）再回到工作台，**正在进行的生成不会中断**，
> 回来后确认卡片、进度和对话都还在原地。

## 六、下载并使用模型

### 6.1 下载 STL

点击 **[下载 STL]**，会弹出系统的「另存为」窗口 —— 你选保存位置与文件名，确认后即可；
下载完成会提示实际保存路径。在浏览器里使用时若不支持弹窗口，会自动退回到浏览器下载。

同时，软件已经自动把文件放到了你的项目文件夹里：

```
文档\AI-3D-Forge\Projects\<项目名>-<编号>\
    model.scad    ← 设计源码（可以用 OpenSCAD 打开继续编辑）
    model.stl     ← 3D 模型文件（给切片软件用）
    model.3mf     ← 同一个模型，但带毫米单位与机型/材料信息
    export\       ← 导出副本
```

点击 **[下载 SCAD]** 可以下载设计源码；点击 **[打开文件夹]** 直接到存放位置。

**之前做过的模型也能下载**：在左侧项目列表里点开它，结果卡片上就有同样的下载按钮
（包括尺寸、面数、体积等实测信息），不必重新生成。

### 6.2 先看「需求核对表」再决定打不打

结果卡片里有一块 **需求核对**，把你提到的每一条要求与**实测几何**逐条对账：

| 状态 | 含义 |
|---|---|
| 达成 | 程序量过了，与要求一致（在公差内） |
| 未达成 | 量过了但没做到，会写明「要求 100mm / 实测 92.4mm / 偏差 -7.6% / 公差 ±2mm」 |
| 没测出来 | 程序该量却量不到（例如要核对孔径但模型上没有居中孔）——**不算通过** |
| 需确认 | 这类要求本质上要靠看（例如「整体像不像一个笔筒」），交给外观复核和你 |

- 公差来自你在设置里选的机型（例如 H2D ±0.15mm、通用机 ±0.25mm），再加 2% 的兜底。
- 标着「工艺建议」的行（壁厚、支撑量、面数、成型范围）是打印质量提醒，
  **不算你没做到的需求**，但值得在切片前看一眼。
- 抬头那个「N/M 达成」就是这套数字的总览；有任何一条未达成，卡片下方会给出下一步怎么做。

> 这张表是程序**量出来的**，不是 AI 说的：数字来自对你下载的那个 STL 的实测。

### 6.3 下载 3MF（给切片软件更稳）

点击 **[下载 3MF]**。它和 STL 是同一个模型（面数完全一致），但多了两件关键的事：

- **明写单位为毫米（mm）**：STL 本身不带单位，导入切片软件时偶发被当成其他单位，
  表现为“模型突然大 10 倍 / 小 100 倍”，还得手动缩放；3MF 不会。
- **带上机型、材料、设计尺寸**：导入后在切片软件里能直接看到这个模型按什么机型生成。

Bambu Studio、OrcaSlicer、PrusaSlicer、Cura、Creality Print 都直接支持 3MF。
旧项目没这个文件也没关系：点一次下载会当场从已交付的 STL 转一个，下次直接取。

### 6.4 一键送到切片软件（省掉“找文件 → 打开软件 → 导入”）

模型生成完，结果卡片上会多一个 **[送到切片软件]** 按钮。点一下就直接用切片软件打开这个模型，
不用你自己去找文件存在哪。这个按钮只在**真的检测到切片软件**时才出现 ——
没装就不摆一个点了只会报错的死按钮。

- 送过去的是 **3MF**（带毫米单位与机型/材料信息），只有 3MF 写不出来时才退回 STL。
- 默认送给哪个软件？软件自己检测：已安装的 Bambu Studio、OrcaSlicer、PrusaSlicer、Cura、
  Creality Print 等都在识别范围内，**实测跑通过的排在最前**。
- 想换一台：去 **设置 → 切片软件**，一行里就能选默认目标、**[重新检测]**（刚装完切片软件时用）、
  或 **[手动指定主程序]**（绿色版、装在冷门目录时自己指出 `.exe`）。
- 送完会告诉你实际发生了什么。“已启动但没真正脱离”这类情况不会粉饰成成功，而是直说原因。

> 每次送出都会留一份快照 `<项目名>-r<版本>.3mf`，每个项目只留最近 5 份。
> 所以切片软件打开后你把本软件关了，它也不会突然报“文件不存在”。

### 6.5 自己手动导入切片软件

1. 打开你的切片软件（Cura、PrusaSlicer、Bambu Studio、OrcaSlicer 等）
2. 把下载的 `.3mf`（或 `.stl`）文件拖进去
3. 选择你的打印机和材料（PLA / PETG 等）
4. 点击切片 → 导出 G-code
5. 拷到打印机开始打印

**小提示**
- 首次打印建议先用 0.2mm 层高、20% 填充
- 承重件建议把填充提高到 40% 以上，或增加壁厚
- 模型尺寸显示在预览窗口角落，注意别超过你打印机的成型范围

## 七、常见问题

### 安装相关

**Q：安装时提示需要管理员权限？**
A：创建开始菜单和桌面快捷方式需要这个权限。点击「是」即可。如果公司电脑不允许，可以改用手动解压版。

**Q：能装在 C 盘以外的盘吗？**
A：可以，安装时点「浏览」选择位置。安装程序默认就会优先选 D 盘，帮你省下 C 盘空间。

**Q：卸载后我的模型会丢吗？**
A：不会。模型和 API Key 都存放在你的用户目录中，卸载程序不会碰它们。重新安装后项目列表会自动恢复。

### OpenSCAD 相关

**Q：自动安装 OpenSCAD 失败怎么办？**
A：软件会告诉你失败原因（网络、权限、磁盘空间）。你也可以手动安装：
1. 打开 [openscad.org](https://openscad.org/)
2. 下载 `OpenSCAD-2021.01-x86-64-Installer.exe`
3. 双击安装（一路「下一步」）
4. 回到软件，点击 **[重新检测]**，会自动识别，不需要手动填路径

**Q：我自己已经装了 OpenSCAD，软件没找到？**
A：打开 **设置 → 3D 引擎**，点击 **[浏览…]** 手动选择 `openscad.exe` 的位置即可。

**Q：提示「OpenSCAD 无法运行」？**
A：打开 **系统诊断** 页面，找到「3D 引擎」一组，点击 **[自动修复]**。

### DeepSeek API 相关

**Q：提示「API Key 无效」？**
A：检查三件事：
1. Key 是否复制完整（以 `sk-` 开头）
2. 账户是否有余额（[platform.deepseek.com](https://platform.deepseek.com/) 可以查看）
3. 网络是否能访问 `api.deepseek.com`

**Q：提示「余额不足」？**
A：需要去 DeepSeek 开放平台充值。

**Q：API Key 会被上传吗？**
A：不会。Key 只保存在你本机的 Windows 凭据管理器里，只在调用 DeepSeek 时使用。

**Q：提示「网络请求失败」或「无法连接」？**
A：软件会把**失败类型和目标地址**一起告诉你（例如超时、连接被拒绝），
方便你判断是断网、代理还是公司网络限制。稍等几秒重试即可；
软件对「连都连不上」这类错误会自动重试一次，但**不会重复发送已经发出去的请求**，
所以不会出现一句话扣两次费的情况。

### 生成模型相关

**Q：生成的模型不是我想要的？**
A：把需求写得更具体。比如把「做个支架」改成「做一个能放 6.7 寸手机、倾斜 60 度、高度 100mm 的桌面支架」。也可以基于当前模型继续提修改要求。

**Q：提示「模型代码存在错误」？**
A：软件会自动让 AI 根据真实报错修复一次。如果还失败，换一种说法再试。

**Q：生成很慢或者卡住了？**
A：复杂模型需要更长时间。超过 2 分钟可以点「停止」，然后把需求简化一些（例如减少镂空细节）。
点「停止」后马上就能继续发下一条消息，输入框里已经打了一半的字也不会被清掉。
就算生成真的卡死了（网络断了之类），软件也会在 2 分钟没有进展时**自动停下来**并告诉你，
不会一直锁着不让你输入。

**Q：STL 下载后打不开？**
A：确认下载完整（后缀是 `.stl`）。也可以直接从项目文件夹里取：
**设置 → 文件位置 → [打开项目文件夹]**。

**Q：关掉软件之后，后台还有 OpenSCAD 在跑吗？**
A：没有。软件退出时会连带结束自己启动的所有子进程（包括正在算的 OpenSCAD），
不需要你去任务管理器手动清理。

**Q：预览里标出来的尺寸和实际打出来的不一致？**
A：预览里的尺寸直接量自导出的 STL（不是参数表里的目标值），
取的是模型在打印坐标系里的 X/Y/Z 三轴跨度，与切片软件里的尺寸同源。
如果你开了「尺寸超出自动处理」（见 [4.9](#49-尺寸超了会自动处理)），
自动缩放后的结果会以 STL 为准，所以预览标的是缩放后的真实数字。

**Q：界面切换时的动画能不能关掉？**
A：可以。软件会自动跟随系统的「减少动效」设置（Windows：
设置 → 辅助功能 → 视觉效果 → 动画效果关掉），关掉后页面切换与进度提示
的动画会自动降到几乎不可见，功能完全不受影响。

### 其他

**Q：液态玻璃下弹窗和菜单会不会跟着变透、看不清字？**
A：不会。透明度滑块只作用于页面内的面板；弹窗、下拉菜单、提示条和预览里的浮层
始终用厚玻璃（实底下限钉在 94%），因为它们背后压着整页文字或 3D 场景。
这个数字是像素实测出来的：不钉住的话，60% 透明度时弹窗正文只剩 1.84:1（阅读无障碍的
国际标准是 4.5:1），就是那种“好看但读不了”的档位。

**Q：生成模型要花多少钱？**
A：按 DeepSeek 的用量计费，一次设计通常远低于 1 分钱。用「应用参数」调整尺寸不消耗额度。

**Q：模型能商用吗？**
A：模型由 AI 根据你的描述生成，你可以自由使用。但请在打印前自行确认强度与安全性，尤其是承重件。
（软件本身的代码采用 MIT 许可证，见 [LICENSE](../LICENSE)。）

**Q：软件需要联网吗？**
A：设计模型时需要联网（调用 DeepSeek AI）。已经生成好的项目和 3D 预览完全离线可用。
软件**不会**上传你的模型或项目。

## 八、遇到问题时怎么求助

软件内置了 **系统诊断** 页面（顶栏上就有这个入口，不在设置里），它会按分组逐项检查：

```
AI 服务      ✓ DeepSeek API 正常
3D 引擎      ✓ OpenSCAD 正常
模型生成     ✓ CLI 测试成功
STL 预览     ✓ Three.js 正常
文件系统     ✓ 正常
网络         ✓ 正常
运行环境     ✓ 原生窗口组件就绪
```

哪一项出问题，旁边就会有 **[自动修复]** 按钮。

如果自己解决不了：
1. 打开 **系统诊断** → 点击 **[全部重新检测]**
2. 把日志一并提供给技术支持。日志文件叫 `aiforge.log`，它跟设置**不在**同一个目录：
   **设置 → 文件位置 →「配置与缓存」那行下方直接写出了日志目录的真实路径**
   （默认 `%LOCALAPPDATA%\AI-3D-Forge\logs`），到那里把 `aiforge.log` 拷出来就行

日志里不会包含你的 API Key（软件会自动打码）。

如果是**软件本身的缺陷**或**安全问题**，请按
[CONTRIBUTING.md](../CONTRIBUTING.md) 与 [SECURITY.md](../SECURITY.md) 里的方式反馈。
